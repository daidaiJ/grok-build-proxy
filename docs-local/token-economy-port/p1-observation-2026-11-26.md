## 0. 结论

**改善，幅度中等，建议保留。**

- 长回合（20+ 调用）输入侧成本 **-9.3%**（常规 6 天基线）到 **-27%**
  （变更前高上下文基线）；总成本 **-4.6%** 到 **-22%**，差额来自 post
  输出量 +46%。50+ 调用桶方向一致。
- P1 的 10–20% 目标在**高上下文长回合**达标（总成本 -21%，等输出口径 -24%）；
  **常规长回合**在等输出口径约 -9%，接近目标；实际总成本被输出增长掩盖。
- 缓存命中均值 97.94% vs 98.67%，中位数仍为 **99.01%**；下降集中在 9 次
  history rewrite 后的第一调用，7/9 下一调用恢复，其余 2–3 调用恢复。
  命中损失约 $0.15–0.20，抵消输入侧节省的 8–29%（常规基线分母更小）。
- 上下文尾部明显变薄：>200k 调用占比 24.3%→17.5%，>300k 1.3%→0；
  中位数 128k→131k，基本回到常态。

## 3. 分析

### 3.1 成本改善来自哪里

策略直接作用在 prompt 上。20+ 长回合的 prompt/call 从 146.1k（常规）/
183.4k（近端）降到 128.6k；按实际缓存价，输入成本降到 $0.00418/call。
命中下降 0.8–1.1pp，在 128.6k prompt 上只增加约 $0.00017/call；输入侧
净节省 $0.00043（常规）到 $0.00154（近端）/call。

输出量从 729/747 升到 1,061/call，增加 $0.00019–0.00020/call，几乎吃掉常规基线
的全部节省。这是工作量差异；按输入侧看，策略成本仍在下降。等输出口径下
常规长回合仍 -8.5%，近端 -25%。

### 3.2 命中下降的性质

- 中位数 99.01%，与变更前 99.13–99.28% 基本一致；均值下降由 4.7% 的
  低命中调用（重写 + 新前缀首调用）拉低。
- 每次重写只影响 1–3 个调用；缓存重新预热后恢复 99%。
- 5 天低命中调用额外成本约 $0.15–0.2；相对输入侧节省，占 8–29%
  （常规基线分母更小）。
- 结论：命中率指标变差是重写瞬间的采样效应，缓存策略本身健康。

### 3.3 压缩行为

- 8 次 diet 都在 20 calls/turn、prompt ≥200k 的门槛上触发，没有短回合误触。
- 没有“清理 → 恢复 → 再清理”循环；没有重复终端命令；2 个会话有少量重复
  读文件（7/21、2/6），不构成系统性重读。
- 全量压缩 5 天 2 次；11-21 单日 7 次 history rewrite（含基准）作为参照，
  全量压缩频率明显下降，但没有做严格同比。
- `read_tool_result` 全程 0 次调用；sidecar 未发版，stub 不可直接恢复。
  当前靠“重跑工具/重读文件”兜底，观察期内没有形成循环。

### 3.4 归因与限制

- Post 会话更短、输出更高；总成本对比受工作量结构影响，输入侧对比更接近
  策略本身。
- 常规基线 vs 近端基线差异大（$5.05 vs $6.16/call），本文同时保留两个口径，
  不挑单边结论。
- 样本为 5 天、6 个 diet 会话、2 次全量压缩；统计功效有限，长程结论需继续
  累积。
- 计价按实际账单费率；若 relay 费率变化，绝对美元需重算，比例结论仍可用。

## 4. 判定与风险

**判定：改善成立，保留策略。** 主要收益来自工具结果回放：
62.4k → 45.2k/call（-28%）；reasoning 回放 32.8k → 42.8k/call（+30%），
在 post reasoning 生成量更高的背景下没有同步下降，已成为下一轮的首要杠杆。

风险与未兑现：

1. idle-wait 压缩 0 次触发；当前样本里它是休眠的。若两周后仍为 0，调触发
   条件或按“未上线”处理。
2. sidecar / `read_tool_result` 未发版；stub 不可恢复。出现重跑循环时优先补。
3. relay anchor 24 条用户消息缺 1 条；继续用
   `relay_summary_verbatim_missing` 观察，长期为 0 可评估关闭。
4. 10–20% 目标在高上下文长回合达标；常规长回合总成本 -5%，等输出约 -9%。
   对外表述应带基线与输出口径，避免把工作量差异算成策略收益。
